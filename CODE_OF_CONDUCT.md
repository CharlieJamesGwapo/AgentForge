# Code of conduct

Participants should communicate respectfully, welcome good-faith questions, criticize work rather than people, respect privacy, and avoid harassment, threats, discrimination, doxxing and unwanted contact. Technical disagreement is welcome when grounded in evidence.

Do not share another person's private information or secrets in code, discussions or reports. Respect boundaries and stop unwanted behavior when asked.

No enforcement team or reporting address has been established. If a problem occurs, preserve a minimal private record and seek a verified project owner through a channel you already trust. The repository owner should establish a confidential reporting route and proportionate enforcement process for the public project. No response timeline or enforcement commitment is implied by this document.
