# Benchmark results

No general token-savings or performance claim is made. The reproducible local fixture report is printed by `npm run benchmark`; its test-like assertions confirm exact duplicate removal and preservation of code/distinct lines. Results vary with input, language and tokenizer and are not provider telemetry.

Use actual project text and inspect retained constraints before adopting compacted prompts. A full cross-language, provider-tokenizer evaluation has not been performed.
