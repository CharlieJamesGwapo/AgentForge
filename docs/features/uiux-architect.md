# UIUX Architect

The portable UIUX Architect skill guides discovery of user journeys, information hierarchy, visual constraints, responsive behavior, accessibility and verification. It includes explicit inputs, artifacts and acceptance criteria in the bundled definition.

There is no screenshot generator, browser automation or UI model adapter in the CLI. Use the skill with a human or compatible coding agent that actually has the needed design/browser tools. Do not claim a UI was rendered, accessibility-tested or visually checked without real evidence.
