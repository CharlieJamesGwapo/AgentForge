# Governance

AgentForge is a public development project hosted at [CharlieJamesGwapo/AgentForge](https://github.com/CharlieJamesGwapo/AgentForge), under the GitHub account `CharlieJamesGwapo`. Repository ownership identifies the hosting account; no separate maintainer roster, governing body or voting process is established. This document records the working review approach, not an established organization.

The actual project owner decides what to adopt and when to distribute it. Contributors should propose focused, testable changes and identify permissions, compatibility impact and evidence. Architecture changes should preserve provider-neutral interfaces, local-first behavior and truthful capability reports.

Before a public release, the owner must review contribution rights and copyright attribution, identify maintainers who consent to ownership duties, establish support and private security reporting, and select a release policy. Add CODEOWNERS only after handles and repository access are verified. Add funding configuration only after verifying a real destination and authorization to use it.
